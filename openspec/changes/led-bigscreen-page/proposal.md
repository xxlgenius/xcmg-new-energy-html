# 提案：新能源产业 LED 大屏交互页面

## Why

徐工新能源产业介绍需要一个 7040×1800（物理 6.6m×1.68m，比例 3.91:1）的 LED 大屏交互页面，替代静态 PPT 演示。现有 PPT 内容分布在 3 页幻灯片中，现场讲解时需要在页面间翻页、无法自主浏览。需要一个单页 Web 应用，把 PPT 的全部素材整合到一块屏上，分左中右三个面板各自独立交互，支持红外触屏滑动与点击。

## What Changes

- 新增纯静态单页应用（`index.html` + CSS + 原生 JS，无构建依赖），固定 7040×1800 设计画布，`transform: scale()` 自适应缩放至任意视口；大屏原生分辨率下像素级还原
- **左屏 · 产品型谱**：4 个产品分类（纯电 12 款 / 拖电 7 款 / 混动 2 款 / 补能 4 款）侧边竖排标签 + 每行横向滑动浏览；点击产品卡片触发整屏转场动画（卡片框消散）后显示满屏「产品介绍」详情卡（产品图 + 规格键值 + 产品特点），可关闭返回型谱；仅影响左屏
- **中屏 · 精益制造**：3 个子屏左右滑动切换——① 新能源产能布局指标卡（1 领航专线 / 5 智能混线 / 10000+ 制造产能）+ 数字孪生工厂视频区；② 数智化制造与运营管理技术 8 张技术卡（各带内嵌视频）；③ 自主可控核心部件（8 类自研 / 3 类独有 + 8 张部件卡）
- **右屏 · 场景解决方案**：9 个工况场景卡 3×3 九宫格，点击后在该屏范围内放大播放视频，可关闭返回九宫格
- **素材管线**：提供从源 PPT 自动抽取素材的脚本，将 25 款产品图与详情数据、8 段技术视频、9 个场景视频/图片、核心部件图、指标与文案抽取为 `assets/` 目录 + `data.js` 数据文件；所有素材位类型正确（视频位放视频、图片位放图片），具体内容后续可无侵入替换
- 视频统一 muted + autoplay + loop 策略，兼容浏览器自动播放限制与触屏大屏场景

## Capabilities

### New Capabilities

- `screen-shell`：全屏外壳——7040×1800 固定画布、等比缩放适配、暗蓝科技风背景与面板边框视觉、Pointer 事件统一处理（触屏手势 + 鼠标）
- `product-spectrum`：左屏产品型谱——分类行横滑、产品详情卡转场开合、详情内容展示
- `lean-manufacturing`：中屏精益制造——三子屏滑动切换、指标卡、孪生视频区、技术卡视频墙、核心部件墙
- `scenario-solutions`：右屏场景解决方案——九宫格浏览、屏内放大视频播放与关闭

（无——全新项目，无既有能力）
