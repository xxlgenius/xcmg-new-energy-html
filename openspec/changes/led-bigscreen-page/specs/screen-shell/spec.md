## Purpose

全屏外壳能力：为 LED 大屏提供 7040×1800 固定设计画布与等比缩放适配、左中右三面板布局骨架、暗蓝科技风视觉（背景/边框/标题条），以及触屏与鼠标统一的指针交互基础。所有面板能力都运行在此外壳之上。

## ADDED Requirements

### Requirement: 固定设计画布与等比缩放

页面内容必须按固定的 7040×1800 设计画布进行布局。运行时页面必须将整个画布等比缩放（保持 3.91:1 宽高比）适配当前浏览器视口，居中显示，多余区域留黑边；在任何视口尺寸下内容不得变形、不得出现滚动条。当视口恰好为 7040×1800 时必须 1:1 像素呈现。

#### Scenario: 普通开发机预览

- **WHEN** 在 1920×1080 的浏览器窗口打开页面
- **THEN** 整个 7040×1800 画布等比缩小后完整可见（约 1920×490），上下留黑边，内容比例不变形

#### Scenario: 大屏原生分辨率

- **WHEN** 浏览器全屏运行在 7040×1800 的 LED 控制端
- **THEN** 画布 1:1 呈现，铺满全屏无黑边无滚动条

### Requirement: 左中右三面板布局

画布必须划分为左、中、右三个相互独立的面板：左屏为产品型谱、中屏为精益制造、右屏为场景解决方案。每个面板必须有独立的容器边界，任一面板内的状态变化（弹层、切换、滚动）不得改变其他面板的布局或内容。

#### Scenario: 面板独立性

- **WHEN** 在左屏打开某产品的详情卡
- **THEN** 中屏与右屏的画面内容与位置保持不变

### Requirement: 暗蓝科技风视觉

页面必须呈现与源 PPT 一致的暗蓝科技风：深蓝渐变背景（含透视网格地面元素）、发光蓝色描边卡片框、带角标与英文副标题的面板标题条。面板边框与卡片框必须以 CSS 绘制（不得使用 PPT 中带死框的整图背景），在 7040 原生分辨率下边缘清晰无糊边。

#### Scenario: 视觉风格一致性

- **WHEN** 页面渲染完成
- **THEN** 三个面板均带统一风格的标题条（中文主标题 + 英文副标题）与发光边框，背景为暗蓝渐变 + 网格地面，整体观感与 PPT 页面一致

### Requirement: 统一指针交互

所有滑动与点击交互必须基于统一的指针事件模型，红外触屏触摸与鼠标操作行为一致：单指拖拽驱动行内横向滚动与子屏切换，点击触发打开/关闭。触屏拖拽时不得触发页面级默认行为（如页面滚动、文本选择、图片拖拽）。

#### Scenario: 触屏滑动

- **WHEN** 用户在左屏某产品行上水平拖动手指
- **THEN** 该行卡片随手指横向滚动，带惯性滑动，其他行与其他面板不受影响

#### Scenario: 鼠标等价操作

- **WHEN** 用户用鼠标左键拖拽同一产品行、或用鼠标滚轮在该行上滚动
- **THEN** 产生与触屏拖动等价的横向滚动效果

### Requirement: 媒体降级展示

视频槽位加载或播放失败时必须降级显示该槽位的封面静态图，不得出现黑块或脚本错误；图片缺失时必须显示同尺寸占位框。页面任一媒体资源失败不得影响其他面板的正常渲染与交互。

#### Scenario: 视频播放失败降级

- **WHEN** 某视频文件缺失或编码不被浏览器支持
- **THEN** 该槽位持续显示其封面图，页面其余部分正常工作，控制台无未捕获错误
